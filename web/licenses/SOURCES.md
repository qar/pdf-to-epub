# 第三方源码与许可

浏览器应用使用 `epubcheck-standalone@5.4.0-build3`。这是第三方维护的 EPUBCheck 源码编译构建，不是 W3C 官方浏览器发行包。未修改该包或它内嵌的组件源码。

- 包与 TeaVM 适配源码：https://github.com/jlarmstrongiv/epubcheck-standalone
- EPUBCheck 5.4.0 源码与依赖许可：https://github.com/w3c/epubcheck/releases/tag/v5.4.0
- Saxon-HE 11.4（MPL-2.0）对应源码：https://github.com/Saxonica/Saxon-HE/tree/main/11/source
- TeaVM 0.15.0 源码：https://github.com/konsoletyper/teavm/tree/0.15.0
- JZlib 1.1.3 源码：https://github.com/ymnk/jzlib

本目录中的许可证原文取自 EPUBCheck 5.4.0 发布包的 `licenses/`。前端同时打包 npm 依赖的 LICENSE、EPUBCheck 编译包的 THIRD-PARTY-NOTICES.txt 和 Source Serif 4 的 OFL。浏览器书库中的“第三方许可”可下载这些文本，断网后也可读取。
